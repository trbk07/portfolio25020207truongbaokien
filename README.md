# Portfolio môn Nhập môn Công nghệ số và Trí tuệ nhân tạo

Website tĩnh của Trương Bảo Kiên, MSSV 25020207, lớp K70I-IT4.

## Cấu trúc

- `index.html`: nội dung portfolio.
- `styles.css`: giao diện responsive.
- `script.js`: danh sách báo cáo PDF và trình xem trực tuyến.
- `assets/`: ảnh cá nhân, infographic và các file PDF báo cáo.

## Deploy GitHub Pages

1. Tạo repository mới trên GitHub.
2. Đẩy toàn bộ thư mục này lên repository.
3. Vào `Settings` -> `Pages`.
4. Chọn `Deploy from a branch`, branch đang dùng của repo này, thư mục `/root`.
5. Sau khi publish, mở đường dẫn dạng `https://ten-tai-khoan.github.io/ten-repo/`.

Các URL PDF trong trang sẽ tự sinh theo domain GitHub Pages sau khi deploy.
